# بوت حساب البروتين في العليقة

بوت تيليجرام بالأزرار: اختار الخامات والكميات ← يحسب البروتين ← يبعتلك ملف إكسل متعدّل.

## المميزات
- **الملف**: فيه الخامات اللي اتحددت بس (الباقي بيتشال)، ونسبة كل مكون في الخلطة %، كجم/طن، سعر الطن، تكلفة الطن (والمجموع 100%).
- 🎯 **بروتين مستهدف** + نصيحة (ضيف كام كجم كسب صويا / ذرة عشان توصل للهدف).
- ⚖️ **تحجيم الخلطة** لأي وزن (500 كجم، طن، 5 طن...).
- 💾 **حفظ الخلطات** (لحد 20) والرجوع لها.
- 💵 **الأسعار**: سعر الطن لكل خامة وتكلفة الخلطة.
- 📢 **اشتراك إجباري** في القناة (`@KIRA349A`).
- 🛠 **لوحة أدمن**: إحصائيات، **برودكاست**، حظر/فك حظر، ملف المستخدمين CSV.
- 🐄 **التعرّف على سلالة الماشية من صورة** (9 سلالات) — الموديل من مشروع Cattle Insight Hub، وبيتسحب من ريبو خاص (شوف تحت).
- بيانات المستخدمين بتفضل بعد إعادة التشغيل.
- 📥 **استيراد المستخدمين القدام**: `/import` وابعت الأرقام (أو ملف txt/csv) عشان يوصلهم البرودكاست. تيليجرام بيسمح للبوت يبعت بس للي سبق وبدأوا معاه.

## النشر وتتبع المصادر
- `/links` (للأدمن) بيديك لينكات جاهزة لكل منصة: `https://t.me/اسم_البوت?start=fb` (fb/wa/tg/yt/tt/ig/x/grp) — كل مستخدم جديد بيتسجّل على المصدر اللي جه منه وبيظهر في لوحة الأدمن.
- زرار «📣 شارك البوت» في القائمة، ورابط البوت تحت جدول الإكسل وفي الكابشن (`WATERMARK=0` يقفله).

## الإعداد
| المتغير | المعنى |
|---|---|
| `BOT_TOKEN` | توكن البوت من @BotFather (**إجباري**) |
| `ADMIN_IDS` | رقمك (ID) — ابعت `/id` للبوت تعرفه. أكتر من أدمن: افصل بفاصلة |
| `CHANNEL_USERNAME` | القناة الإجبارية (الافتراضي `@KIRA349A`) |
| `REQUIRE_SUBSCRIPTION` | `0` لإيقاف الاشتراك الإجباري |
| `COMMAND_MENU` | `0` يشيل قائمة الأوامر (زرار Menu جنب خانة الكتابة) خالص. الافتراضي: قائمة محدّثة من 4 أوامر |
| `RECALC` | `0` لإيقاف إعادة الحساب بـ LibreOffice |
| `DATA_FILE` | مكان ملف البيانات (الافتراضي `bot_data.json`) |

**مهم للاشتراك الإجباري:** لازم تضيف البوت **أدمن** في القناة، وإلا مش هيعرف يتحقق (وساعتها بيسيب الناس تشتغل وبيبعتلك تنبيه).

## التشغيل العادي
```bash
pip install -r requirements.txt
export BOT_TOKEN="..." ADMIN_IDS="123456789"
python bot.py
```

## التشغيل على GitHub Actions
الملف `.github/workflows/bot.yml` بيشغّل البوت (كل 6 ساعات، وعند أي push، ويدوي من تبويب Actions).
Settings ← Secrets and variables ← **Actions** ← New repository secret: `BOT_TOKEN` و `ADMIN_IDS`.

**حفظ البيانات:** السيرفر بيتمسح مع كل تشغيل، فالبوت بيحفظ نسخة احتياطية (ملف `bot_data.json`) **مثبّتة في شات الأدمن مع البوت** وبيتحدّث تلقائياً ويستعيدها عند التشغيل.
لازم الأدمن يكون عمل `/start` للبوت، وما يمسحش الرسالة المثبّتة ولا يثبّت رسائل تانية في الشات ده.

## ميزة التعرّف على السلالة
المستخدم يبعت صورة (أو يدوس «🐄 تعرّف على السلالة») والبوت يرد بأعلى 3 سلالات ونسبة ثقة الموديل. السلالات: أنجس، إيرشاير، براون سويس، هيرفورد، هولشتاين فريزيان، جعفرآبادي، جيرسي، ريد دين، سيمنتال.

- الموديل **مش مرفوع على الريبو العام**. الـ workflow بيسحب `cattle_model.h5` و `labels.json` من الريبو الخاص `kareemzeiad60-dot/111122` (مجلد `artifacts/cattle-predict`) وقت التشغيل.
- لازم secret باسم **`MODEL_REPO_TOKEN`**: توكن GitHub بيقرا الريبو ده (Fine-grained: Repository access ← الريبو ده بس، Permissions ← Contents: **Read-only**، مدة صلاحية طويلة). من غيره البوت يشتغل عادي والميزة تتقفل.
- تشغيل عادي: حط `cattle_model.h5` و`labels.json` في `models/` (أو `CATTLE_MODEL_DIR`) و`pip install -r requirements-cattle.txt`.
- الموديل مفيهوش خانة «مش بقرة»، فأي صورة هيحاول يطابقها على السلالات التسعة. الرد بيوضّح كده.

## ملفات المشروع
`bot.py` (الأزرار والبوابة) • `admin.py` (الأدمن والبرودكاست) • `storage.py` (حفظ البيانات) •
`breed.py` (التعرّف على السلالة) • `feed_core.py` (الحساب والإكسل) • `Feed_Calculator_Bilingual.xlsx` (القالب) • `test_*.py` (اختبارات)

المعادلة: `بروتين الخامة = الكمية × المادة الجافة% × البروتين%` — نسبة البروتين = إجمالي البروتين ÷ إجمالي الوزن.
أسماء بديلة للخامات (مثلاً «سوداني») تتضاف في `ALIASES` أعلى `feed_core.py`.
