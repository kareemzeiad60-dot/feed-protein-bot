# بوت حساب البروتين في العليقة

بوت تيليجرام بالأزرار: اختار الخامات والكميات ← يحسب البروتين ← يبعتلك ملف إكسل متعدّل.

## المميزات
- **الملف**: فيه الخامات اللي اتحددت بس (الباقي بيتشال)، ونسبة كل مكون في الخلطة %، كجم/طن، سعر الطن، تكلفة الطن (والمجموع 100%).
- 🎯 **بروتين مستهدف** + نصيحة (ضيف كام كجم كسب صويا / ذرة عشان توصل للهدف).
- ⚖️ **تحجيم الخلطة** لأي وزن (500 كجم، طن، 5 طن...).
- 💾 **حفظ الخلطات** (لحد 20) والرجوع لها.
- 💵 **الأسعار**: سعر الطن لكل خامة وتكلفة الخلطة.
- **Mini App تيليجرام**: واجهة عربية للموبايل لحساب الخلطة، الأسعار، الهدف والتحجيم، حفظ الخلطات وتنزيل Excel.
- 📢 **اشتراك إجباري** في القناة (`@KIRA349A`).
- 🛠 **لوحة أدمن**: إحصائيات، **برودكاست**، حظر/فك حظر، ملف المستخدمين CSV.
- 🐄 **التعرّف على سلالة الماشية من صورة** (موديلين: 10 و9 سلالات، الأدمن يبدّل بينهم بـ `/model`) — الموديل من مشروع Cattle Insight Hub، وبيتسحب من ريبو خاص (شوف تحت).
- بيانات المستخدمين بتفضل بعد إعادة التشغيل.
- 📥 **استيراد المستخدمين القدام**: `/import` وابعت الأرقام (أو ملف txt/csv) عشان يوصلهم البرودكاست. تيليجرام بيسمح للبوت يبعت بس للي سبق وبدأوا معاه.

## النشر وتتبع المصادر
- `/links` (للأدمن) بيديك لينكات جاهزة لكل منصة: `https://t.me/اسم_البوت?start=fb` (fb/wa/tg/yt/tt/ig/x/grp) — كل مستخدم جديد بيتسجّل على المصدر اللي جه منه وبيظهر في لوحة الأدمن.
- زرار «📣 شارك البوت» في القائمة، ورابط البوت تحت جدول الإكسل وفي الكابشن (`WATERMARK=0` يقفله).

## الإعداد
| المتغير | المعنى |
|---|---|
| `BOT_TOKEN` | توكن البوت من @BotFather (**إجباري**) |
| `ADMIN_IDS` | رقمك (ID) — ابعت `/id` للبوت تعرفه. أكتر من أدمن: افصل بفاصلة |
| `CHANNEL_USERNAME` | القناة الإجبارية (الافتراضي `@KIRA349A`) |
| `REQUIRE_SUBSCRIPTION` | `0` لإيقاف الاشتراك الإجباري |
| `COMMAND_MENU` | `0` يشيل قائمة الأوامر (زرار Menu جنب خانة الكتابة) خالص. الافتراضي: قائمة محدّثة من 4 أوامر |
| `RECALC` | `0` لإيقاف إعادة الحساب بـ LibreOffice |
| `DATA_FILE` | مكان ملف البيانات (الافتراضي `bot_data.json`) |
| `WEBAPP_URL` | رابط HTTPS للواجهة (الافتراضي: معاينة GitHub Pages لهذا المشروع؛ اتركه فارغاً لإخفاء زر Mini App) |
| `WEBAPP_PORT` / `PORT` | منفذ خادم الواجهة (الافتراضي `8080`) |

**مهم للاشتراك الإجباري:** لازم تضيف البوت **أدمن** في القناة، وإلا مش هيعرف يتحقق (وساعتها بيسيب الناس تشتغل وبيبعتلك تنبيه).

## التشغيل العادي
```bash
pip install -r requirements.txt
export BOT_TOKEN="..." ADMIN_IDS="123456789"

```

## الاستضافة (الحل الحقيقي لتشغيل 24/7)
GitHub Actions مش مصمّم لاستضافة بوت دايم: الـ job بيقف بعد 6 ساعات، والجدولة بتتأخر أحياناً ساعات، وشروط GitHub بتمنع استخدام Actions في أي نشاط مش متعلق ببناء واختبار ونشر المشروع نفسه (ومنها الـ serverless)، وممكن توقّف الـ jobs أو تقيّد الاستخدام. الـ workflow الموجود حل مؤقت (فجوة حوالي دقيقتين كل 6 ساعات).

للتشغيل الثابت استخدم VPS أو استضافة بتدعم Docker:
```bash
cp .env.example .env        # عدّل BOT_TOKEN و ADMIN_IDS (و MODEL_KEY لو عايز السلالة)
docker compose up -d --build
```
- ملفات `Dockerfile` و`docker-compose.yml` و`entrypoint.sh` لسه **مش مجرّبة على Docker فعلاً** (اتجرّب منطق فك التشفير بس). لو طلعت مشكلة في البناء ابعتها.
- بيانات المستخدمين بتتحفظ في `/data` (volume) **وكمان** كنسخة احتياطية مثبّتة في شات الأدمن، فنقل البوت من Actions لسيرفر مش بيضيّع حاجة.
- لما تشغّله على سيرفر، **وقّف الـ workflow** (Actions ← Run Telegram Bot ← ⋯ ← Disable workflow) عشان ما يشتغلش بوتين بنفس التوكن (خطأ 409).

### إرسال ملف Excel من Mini App إلى البوت
1. فعّل GitHub Pages من إعدادات المستودع باختيار **Build and deployment → GitHub Actions**. بعد نجاح workflow النشر، تكون المعاينة على رابط Pages الموجود في `WEBAPP_URL` في `.env.example`.
2. عند تشغيل البوت على GitHub Actions، يستخدم رابط Pages الافتراضي تلقائياً. على استضافة أخرى، اضبط `WEBAPP_URL` على رابط HTTPS للواجهة.
3. أرسل `/start` للبوت في محادثة خاصة؛ هيظهر زر **🚀 افتح التطبيق وأرسل Excel** أسفل المحادثة. افتح التطبيق من الزر ده، واضغط **📩 ابعت ملف Excel للبوت**؛ البوت يتحقق من الخلطة ويرسل ملف `.xlsx` في نفس المحادثة. لازم فتح التطبيق من زر البوت لأن Telegram `sendData` يرسل بيانات Mini App للبوت من جلسة Telegram.

تعمل GitHub Pages كنسخة ثابتة للتطبيق؛ تحفظ بيانات المعاينة على نفس المتصفح فقط، لكنها ترسل نسخة الخلطة إلى البوت عند الضغط على الزر داخل Telegram. البوت ينشئ ويرسل Excel، وتظل الخلطات الدائمة مرتبطة ببيانات البوت. زر الإرسال لا يظهر عند فتح صفحة Pages في متصفح عادي خارج Telegram.

تتحقق الواجهة من توقيع `initData` المرسل من تيليجرام قبل قراءة البيانات أو تعديلها. لا تفتح مسارات `/api/` للمتصفح خارج تيليجرام، ولا تضع توكن البوت في الواجهة. يتطلب Telegram Mini App رابط HTTPS عامًا؛ `localhost` وحده لا يكفي للنشر.

### معاينة محلية مؤقتة
لتجربة التصميم والحسابات في المتصفح من غير توكن بوت أو استضافة:
```bash
python run_miniapp_demo.py
```
افتح `http://127.0.0.1:8080`. المعاينة محلية فقط، لا تتصل بتيليجرام، وبياناتها مؤقتة وتُحذف عند إيقاف العملية (`Ctrl+C`). لتجربة التطبيق داخل تيليجرام استخدم إعداد النشر العام أعلاه.

### GitHub Pages
الـ workflow `.github/workflows/pages.yml` ينشر معاينة ثابتة من الواجهة تلقائياً على GitHub Pages. هذه النسخة تحسب الخلطة وتحفظ الأسعار والخلطات في `localStorage` على نفس المتصفح، وتصدّر CSV من المتصفح أو ترسل مدخلات الخلطة للبوت من داخل Telegram ليعيد ملف Excel. لا تستخدم Pages لحسابات سرية أو للوصول إلى بيانات البوت مباشرة.

## التشغيل على GitHub Actions
الملف `.github/workflows/bot.yml` بيشغّل البوت (كل 6 ساعات، وعند أي push، ويدوي من تبويب Actions).
Settings ← Secrets and variables ← **Actions** ← New repository secret: `BOT_TOKEN` و `ADMIN_IDS`.

**حفظ البيانات:** السيرفر بيتمسح مع كل تشغيل، فالبوت بيحفظ نسخة احتياطية (ملف `bot_data.json`) **مثبّتة في شات الأدمن مع البوت** وبيتحدّث تلقائياً ويستعيدها عند التشغيل.
لازم الأدمن يكون عمل `/start` للبوت، وما يمسحش الرسالة المثبّتة ولا يثبّت رسائل تانية في الشات ده.

## ميزة التعرّف على السلالة
المستخدم يبعت صورة (أو يدوس «🐄 تعرّف على السلالة») والبوت يرد بأعلى 3 سلالات ونسبة ثقة الموديل. السلالات: أنجس، إيرشاير، براون سويس، هيرفورد، هولشتاين فريزيان، جعفرآبادي، جيرسي، ريد دين، سيمنتال.

- **موديلين شغّالين:** `domestic` (الجديد من مستودع DOMESTIC-CATTLE-AI: أنجس، إيرشاير، **برافورد**، **برانجوس الأسود**، براون سويس، هيرفورد، هولشتاين، جعفرآبادي، جيرسي، ريد دين، MobileNetV2، تجهيز `x/255`) و`insight` (القديم: 9 سلالات بدل برافورد وبرانجوس فيه سيمنتال). الجديد هو الافتراضي (`BREED_MODEL=insight` عشان تغيّره). الأدمن: `/model` يعرض الموديلين ودقة كل واحد من تقييمات المستخدمين، و`/model insight` يبدّل (الاختيار بيتحفظ).
- **مقارنة على 206 صورة هيرفورد من حظيرة (CowDatabase):** الاتنين صفر صح (حتى في أول 3). الموديل الجديد بطريقة `x/255` غلط بثقة 70%+ في 86 صورة. وكانوا بيتفقوا في 42% من الصور، وفي كلها اتفقوا على إجابة غلط. فاتفاق الموديلين **مش** دليل على الصح، وده سبب إني مدمجتهومش «بالتصويت». الحكم الحقيقي هيبقى من تقييمات ✅/❌ لكل موديل في لوحة الأدمن.
- الموديل القديم مرفوع في نفس الريبو **مشفّر** (`models/cattle_model.h5.enc`، AES-256) فمفيش حد يقدر يستخدمه من غير المفتاح. الـ workflow بيفكه وقت التشغيل بمفتاح سري محفوظ في secret باسم **`MODEL_KEY`** ويتأكد من سلامته (`sha256`).
- من غير `MODEL_KEY` (أو لو فك التشفير فشل) البوت يشتغل عادي والميزة تتقفل وبيظهر تحذير في الـ run.
- تغيير الموديل: `./encrypt_model.sh path/to/cattle_model.h5` بيشفّره وبيطبعلك مفتاح جديد تحطه في `MODEL_KEY`، وبعدين ارفع الملفين الجداد.
- تشغيل عادي (من غير Actions): فُك التشفير بنفس أمر الـ workflow أو حط `cattle_model.h5` مباشرة في `models/` وسطّب `pip install -r requirements-cattle.txt`.
- **دقة الموديل على الصور الحقيقية ضعيفة**: اتجرّب على 206 صورة هيرفورد من مستودع CowDatabase (حظيرة، إضاءة من ورا الحيوان) والنتيجة 0% صح، حتى الردود بثقة 70% فأكتر كانت كلها غلط. عشان كده الرد مفيهوش مستوى «ثقة عالية». التحسين الحقيقي محتاج داتا متنوعة بسلالات متعددة وصور من ظروف حقيقية.
- **تقييم النتيجة (لتحسين الدقة):** تحت كل نتيجة أزرار «✅ صح / ❌ غلط». التقييم بيتسجّل كأرقام بس، وبتشوف الدقة التقريبية في لوحة الأدمن بعد 5 تقييمات على الأقل. لو المستخدم قال «غلط» بيختار السلالة الصح، وبعدها بيظهرله زرار **📤 ابعت الصورة للتحسين**: الصورة **مش بتتبعت إلا بموافقته**، وبتوصل لشات الأدمن مع التصنيف (`pred=... truth=...`) من غير اسم المستخدم. دي الصور اللي تتجمّع لإعادة التدريب بعدين.
- الموديل مفيهوش خانة «مش بقرة»، فأي صورة هيحاول يطابقها على السلالات التسعة. الرد بيوضّح كده.
