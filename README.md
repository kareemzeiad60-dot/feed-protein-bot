# بوت حساب البروتين في العليقة

## التشغيل
1. اعمل بوت من @BotFather وخد التوكن.
2. ```bash
   pip install -r requirements.txt
   export BOT_TOKEN="التوكن_هنا"
   python bot.py
   ```
3. (اختياري) لو عندك LibreOffice متسطّب على السيرفر (`soffice`) البوت بيستخدمه تلقائياً عشان القيم تظهر في ملف الإكسل حتى في معاينة الموبايل. لو مش عايزه: `RECALC=0`.

## الملفات
- `bot.py` — أوامر وأزرار تيليجرام
- `feed_core.py` — قراءة الخامات من الملف، تحليل الرسائل، حساب البروتين، تعديل الإكسل
- `Feed_Calculator_Bilingual.xlsx` — القالب (البوت بيقرا منه أسماء الخامات ونسب البروتين، فلو عدّلت فيه البوت يتبعك)
- `test_core.py` — اختبار بيقارن حساب البوت بحساب الإكسل

## بيعمل إيه في الملف
بيكتب الكميات في العمود B بس (الخلايا المفتوحة في الشيت الأول)، وباقي المعادلات والحماية والتنسيق زي ما هي.
المعادلة: `البروتين = الكمية × المادة الجافة% × البروتين%` ← إجمالي البروتين ÷ إجمالي الوزن = نسبة البروتين الخام.
لو عايز أسماء بديلة للخامات (مثلاً «سوداني») زوّدها في `ALIASES` أعلى `feed_core.py`.
